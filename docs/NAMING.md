## 二、为什么是这两个

### 英文名 Sophon —— 造词，符合海外同行实际做法

调研海外 dashcam 品牌后确认，这个品类的品牌名分三类：

1. **实义复合词**：BlackVue / Thinkware / Nextbase / Vantrue —— 全是 **1997–2015 创立的老牌**，那个年代好词还空着；
2. **纯造词（中国出海主力）**：Viofo / IIWEY / PRUVEOO / ZMOPO / DKGEA / Neideso / Azdome / Rexing —— 品牌名**不承载语义**，因为读得出含义的好词注册不下来；
3. **功能名词**：Sentry Mode / Parking Mode / Cloud —— 语义全部搬到功能名上。

背后是一条硬规律：**凡是读得出含义的好词，会先被警用 / 执法 / 车队 / 安防这类 B 端拿去做产品线名**（Argus、Kestrel、Sentinel 都是这样被占走的），留给消费级的只剩造词。

`Sophon` 正落在第 2 类，是「行业正确」的形态。

### 中文名 极视 —— 语感对，字形短，语义实

- **声调**：`jí shì` = 阳平 + 去声（35 → 51），**先扬后压**，念出来有力度，不塌；
- **字数**：两字，无生僻字、无多音字、不会念错；
- **字义**：「极」是**到顶**（不是程度副词），「视」是**看** —— 合起来是"看到极致 / 极远之视"，与四路无死角 + 远望的含义同向；
- **语感**：功能直给型，符合国内行车记录仪品类的品牌语感；
- **社区惯例**：领克 07/08 车友共创生态里的应用命名本就是「作者昵称（应用名）」，随手起、不查商标 —— 极视在这个生态里**未被占用**。

### 法律依据（框架性，非法律意见）

- **《商标法》第 48 条**：把"商标的使用"限定为"**用于商业活动中**……用以识别商品来源的行为"；**第 57 条**为侵权情形。→ 纯自用、不公开发布基本够不上。
- **GPL ≠ 商标许可**：德国杜塞尔多夫高等法院 *xt:Commerce* 案确认 GPL 只授权著作权，**不含任何商标使用许可**（这正是 FOSS fork 必须改名的原因）。
- **《反不正当竞争法》（2025-06-27 修订、2025-10-15 施行）第七条第一款第（三）项**：新增将"**新媒体账号名称、应用程序名称或者图标**"列为受保护的商业标识；混淆行为的核心要件是"**引人误认**"，**不以营利为前提**（第 23 条罚则：无违法经营额也可处 25 万元以下罚款）。→ 风险 2 正落在这一格。
- **实际最先到来的不是诉讼**，而是平台投诉与改名时机：GitHub 有 trademark 政策（有效投诉可要求改仓库名或禁用仓库），应用商店审核更前。
- **"免费开源"能降低风险但不能消除**：公开发布 + README + 图标 + 项目宣传已接近第 48 条列举的"广告宣传"，实务口径明确 **"是否营利不能成为不侵权抗辩理由"**。

### ⚠️ 触发重评估的条件（出现任一即须改名或取得授权）

1. 上架任何应用市场 / 分发平台；
2. 收取赞助、捐赠以外的商业变现；
3. 售卖硬件或提供付费服务；
4. 收到权利方或平台的通知。

改名成本此时仍很低：**README 首行 + 字标 + 应用图标 + 包名**（几分钟）。反之，若等到社区叫法、star、已装包名全部建立之后再改，就变成一次**社区迁移**。
