极视 Sophon · UI 设计系统 v2

以盯盯车 SurCamX 1.4.6（同为 FlymeAuto 生态）为基准重构：建立深色 / 浅色双套语义化 token， 并以「视频为底、控件浮层、无描边卡片」替代旧的荧光青 + 描边玻璃拟态。

01为何推翻旧主题

旧主题的四个结构性问题 —— 这些问题叠加在一起，直观感受就是「廉价感」。

问题旧主题（v1）修正
主色 #1AE5A3 荧光青 + #0A84FF 双主色并存，与 FlymeAuto 原生 #3572F4 冲突 统一为单主色 Flyme 蓝：#3572F4（浅）/ #5B9BFF（深）。青色彻底移除
描边 每张卡片 1dp #233446 / #37506D 亮边，整屏被「框」住 卡片改为 1px 发丝线 --c-line + 柔和双层投影；描边仅保留在视频砖格（capsule 内边框语义）
层级 几乎全部文字 bold + 高饱和着色，无主次 建立 3 级文字 token；加粗仅用于标题与数值；正文回归 400/500
密度 Pill / Badge 堆叠：CH 标签、FPS、REC、挡位、车速同处一行 telemetry 收敛为右上角一组轻量读数；CH 信息随视频砖格内置浮层

02设计语言基准

从盯盯车 activity_main_lynkco07.xml / preview_border.xml 实测反推的四条准则。

01 Video First
视频为底

画面本身就是舞台，不给视频套卡片外壳。砖格 8dp 圆角 + 1.5dp 白色 10% 描边 + 9% 白色填充，仅做边界暗示。

02 Floating Control
控件浮层

操作控件浮动于画面之上：48dp 圆角方块 + 半透明毛玻璃 + 双层投影，而非挤在下方面板里。

03 Single Accent
单一强调色

全界面仅一个强调色，只用于「当前选中 / 主操作 / 需立即注意」。语义色（红黄绿）严格限定在状态语义上。

04 Shadow Depth
投影造景深

三层 elevation：卡片贴地·浮层离地·全屏模态。用阴影而非描边表达层级，暗色环境下同样成立。

关键取舍：盯盯车部分页面仍偏「安卓化」（大量 CardView + 分割线表格）。Sophon 只吸收它的 视频层处理与浮层控制，其余保持更克制的 FlymeAuto 原生感：更少分割线、更多留白与投影层次。
