构成法则

六条规则决定这套界面是否耐看，也是所有 token 的约束来源。

01

视频永远是主角

画面铺满可用区域，不给它套卡片壳。UI 全部浮在画面之上，用毛玻璃 + 内高光与画面分离；画面之间只有 3px 细缝，靠缝而非留白分隔。

preview → stage · UI → overlay
02

一米视距的字阶

车机不是手机。最小可读 11.5px、正文 13.5px、标题 26px、关键数值 30px。所有数值走等宽 tabular 数字，避免跳动。

11.5 / 13.5 / 26 / 30
03

每个模块至少两层信息

主信息 + 副说明 + 数值或徽标。列表行必带时长与容量，设置项必带副标题，省掉「查看详情」这一层操作。

title / sub / meta / badge
04

层级靠投影不靠描边

取消粗描边。层级由双层投影（ambient + key）加顶部 1px 内高光表达；深色模式改用抬升背景色而非加重描边。

sh-1 / sh-2 / sh-3 + inset top
05

单一强调色

全站只有一个强调色。青色彻底移除，红色只留给录制、删除、紧急三类语义——滥用会稀释告警权重。

#3572F4 / #5B9BFF
06

触控目标 ≥ 52px

行车场景手指不稳，可点元素不小于 52×52，危险操作间距额外增加。这是安全底线，不是风格选择。

min target 52dp

色彩 Token

语义化命名，深浅两套同构。深色不是把浅色反转，而是重新校准：背景降到 #11151B，抬升面用 #1A2029 而非纯黑。
