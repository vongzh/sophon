# 极视 (Sophon) 车规级四向视觉与安全系统技术能力矩阵

> **目标平台**：FlymeAuto 智能座舱生态 (龙鹰一号 SE1000 / 高通 8155 / 8295 平台)  
> **设计定位**：工业级四向全维行车记录、智能盲区感知辅助与车联视觉安全系统  
> **核心原则**：**零影响原厂车机、零写内部闪存、零篡改车身总线**。

---

## 一、 核心技术能力与行业方案对照矩阵

| 功能维度 | 行业传统车载记录仪方案 | 常见第三方车载记录仪方案 | 极视 (Sophon) 车规全栈自研方案 |
| :--- | :--- | :--- | :--- |
| **车身信号总线接入** | 仅依赖外接 ACC 取电与重力感应，无车机总线通信能力 | 仅适配单一车型或依赖外部特定闭源中间件，断链后功能完全停摆 | **三合一多源自适应总线 (`VehicleSignalBus`)**：<br>1. 优先直连车规级标准 AIDL 信号服务<br>2. 缺省时自动无缝回退至 Android 原生 `CarPropertyManager`<br>3. 兜底挂接本地只读 UNIX Domain Socket / gRPC 与系统广播，**零外部依赖独立稳定运行** |
| **四路视觉合流录制** | 多路独立视频文件写入，高 I/O 导致存储卡发热降速与丢帧 | 软硬件结合不彻底，视频切片交替时存在 300~600ms 录制盲区 | **OpenGL ES 3.0 统一渲染管线 + 0ms IDR 热切片**：<br>单实例 MediaCodec 硬件硬件编码，连续运转永不停机，切片交接严格 0 毫秒丢帧 |
| **打灯盲区辅助与悬浮窗** | 无打灯辅助或通过外挂屏幕展示，遮挡视线 | 悬浮窗弹窗延迟高，未深度适配原厂倒车/全景逻辑，易导致画面遮挡 | **全场景智能盲区感知与极速避让管线**：<br>1. 转向灯拨动毫秒级呼出对应侧广角补偿悬浮窗<br>2. 结合 Brown-Conrady 广角去畸变与雨夜增强着色器<br>3. **50ms 原厂 AVM 极速避让**：检测到倒车或原厂全景时立即隐藏释放管线 |
| **智能哨兵模式** | 驻车常供电硬录，极易导致 12V 蓄电池亏电变砖 | 自制驻车监听强持系统唤醒锁 (WakeLock)，小电瓶健康风险大 | **智能低功耗哨兵与电量智能守护**：<br>1. 深度协同原厂电源状态机，支持 Wi-Fi 白名单常用地点自动撤防<br>2. 异常振动三轴传感器唤醒录制，内置 12V 蓄电池低压自动断电硬保护 |
| **无感互联与远程控制** | 需频繁拔插 U 盘到电脑读取，或连接慢速专用热点 | 仅支持单一推送通道或依赖专有私有云服务 | **局域网免流 H5 传送门 + 开放式多通道远程调度 (`RemoteDispatcher`)**：<br>1. 车载轻量 HTTP 服务，手机扫码免流量直连秒看秒下<br>2. 原生支持 Telegram Bot / 飞书机器人双向交互、状态看板与紧急抓拍<br>3. iOS 毫秒级 Bark 极速离线告警推送 |
| **存储安全与介质保护** | 频繁擦写车机内部 eMMC/UFS 闪存，易造成坏块死机 | 临时写内部存储再转拷 U 盘，掉电易造成切片损坏 | **纯内存环形缓冲 (Direct RAM -> USB Muxer)**：<br>1. 绝不向车机内部闪存写入音视频数据（No USB, No Write）<br>2. 8MB 内存环形缓存容灾，内置 MP4 Moov 原子修复器防止异常掉电损毁<br>3. 智能 U 盘体检与读写基准评测 (`UsbBenchmark`) |
| **工程架构与代码健壮性** | 单体大文件耦合，无进程隔离，UI 阻塞影响录制 | UI 与录制逻辑混杂在单一 Activity 中，崩溃率高 | **多进程物理隔离 + 纯 Kotlin Clean Architecture**：<br>录制核心服务与 UI 呈现层独立进程运行，即使前台崩溃后台录制与盲区辅助依然安若磐石 |

## 二、 关键技术管线架构

### 1. 多源自适应车身信号总线 (`VehicleSignalBus`)
极视 (Sophon) 统一抽象了车身信号契约层，向下屏蔽车型与通信协议差异：

```mermaid
graph TD
    AIDL_SVC[车规系统标准 AIDL 信号服务]
    NATIVE_VHAL[Android 原生 CarPropertyManager]
    GRPC_BUS[车身总线本地 UNIX Domain Socket / gRPC]
    
    subgraph SOPHON_BUS["Sophon 动态多源自适应信号总线 (VehicleSignalBus)"]
        DISPATCHER[AdaptiveSignalSourceResolver]
        CACHE[VehicleSignalStateCache]
    end
    
    AIDL_SVC -->|1. 优先连接 (AIDL)| DISPATCHER
    NATIVE_VHAL -->|2. 无服务时无缝接管| DISPATCHER
    GRPC_BUS -->|3. 底层协议补充| DISPATCHER
    
    DISPATCHER --> CACHE
    CACHE -->|只读 StateFlow| BLIND_OVERLAY[智能盲区感知悬浮窗]
    CACHE -->|只读 StateFlow| SENTRY_MODE[驻车哨兵智能守护]
    CACHE -->|只读 StateFlow| OVERLAY_CTRL[车身状态与悬浮控制器]
```

- **纯只读订阅原则**：仅注册并监听车速、挡位、转向灯、车门及电源信号，严禁向总线发送任何控制报文，确保原厂电子电气控制安全。

### 2. OpenGL ES 3.0 四路并发与图像调优渲染管线

#### 2.1 智能动态盲区感知悬浮窗
- **智能触发**：
  * 左/右转向灯拨动即时激活对应侧悬浮窗；
  * 低速双闪透视模式：狭窄道路低速会车时自动双侧开窗；
  * DOW (Door Open Warning) 开门防碰撞预警：车速 $< 5\text{ km/h}$ 开门即刻展开后向视觉。
- **Brown-Conrady 广角光学畸变校正**：
  利用车载标定参数实时消除鱼眼镜头畸变，使盲区距离感更加自然真实。
- **雨夜增强着色器 (Rainy Night Shader)**：
  在恶劣雨雪夜间环境下，通过片元着色器自适应调节动态范围与局部对比度，破除水膜与反光遮挡。

#### 2.2 0ms IDR 热切片录制管线
- 硬件编码器持续运转，通过流式复用器在检测到 IDR 关键帧时平滑切换分片文件句柄；
- 切片接缝严格做到 0 毫秒丢帧、0 毫秒黑屏；
- 内置 MP4 封装崩溃急救机制（`Mp4MoovRescuer`），若因车辆熄火或意外断电导致 moov box 缺失，能在下次开机时快速修复重建索引。

---

### 3. 车载免流局域网与开放远程中枢

#### 3.1 车载局域网免流快传 (`LanShareServer`)
- 车机启动高性能轻量级嵌入式 HTTP 服务；
- 手机连入车机 Wi-Fi 或热点后，扫码秒开响应式 H5 交互界面；
- 支持 HTTP 206 断点范围拖动秒播与多选文件批量无损下载，全程零消耗车机 SIM 卡移动流量。

#### 3.2 开放式双向远程控制调度 (`RemoteDispatcher`)
- 整合 Telegram Bot 与 企业飞书 (Feishu) 机器人，支持安全鉴权机制；
- 车主通过移动终端随时发送 `/status`、`/snapshot`、`/clip` 等指令；
- 支持异常离线告警队列与 iOS Bark 毫秒级低延迟推送通道。
